# TemuanKu — Aplikasi Temuan Barang Hilang di Lingkungan Kampus

Website demo front-end untuk tugas proyek kampus.

## Fitur
- Registrasi dan login demo.
- Dashboard dengan ringkasan jumlah laporan.
- Pengelolaan data barang hilang dan barang temuan.
- Tambah, edit, dan hapus laporan.
- Pencarian berdasarkan nama barang, lokasi, pelapor, dan deskripsi.
- Filter jenis laporan dan status.
- Rekap laporan serta fitur cetak.
- Logout.
- Penyimpanan demo di `localStorage` browser.

## Cara menjalankan
1. Ekstrak folder proyek.
2. Buka folder `temuanku` di Visual Studio Code.
3. Buka `index.html` dengan Live Server, atau buka langsung di browser.
4. Buat akun melalui tab **Daftar akun**, kemudian masuk.

## Catatan penting
Ini adalah prototipe front-end untuk pembelajaran. Akun dan laporan disimpan di browser yang sedang digunakan, bukan database online. Jangan gunakan kata sandi asli/pribadi. Untuk penggunaan nyata, dibutuhkan backend, database, autentikasi yang aman, dan kontrol akses.
